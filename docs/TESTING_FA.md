# آزمایش و رفع خطاهای رایج

## بررسی خودکار

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

فرمان‌ها را با Python محیط مجازی اجرا کنید. اجرای تحویل اولیه روی Python 3.12 و Django 5.2.18 انجام شده و ۳۴ تست پاس شده است.

| حوزه | چیزی که بررسی می‌شود |
| --- | --- |
| حساب کاربری | ثبت‌نام، کاربر تکراری، ورود، مقصد امن و خروج با POST |
| مالکیت | جلوگیری از ویرایش، حذف و اعلام فروش آگهی کاربر دیگر |
| انتشار | پنهان‌بودن آگهی خصوصی، تأیید/رد مدیر و بررسی دوباره پس از ویرایش |
| فرم | شماره و مبلغ فارسی، قیمت مشخص/رایگان/توافقی و مقدار نامعتبر |
| تصویر | ذخیره JPEG با نام تصادفی، رد فایل جعلی و بیش از حد حجیم |
| جست‌وجو | ترکیب فیلترها، خطای پارامتر، ترتیب قیمت و صفحه‌بندی |
| نشان و تماس | یکتایی نشان، پنهان‌شدن آگهی غیرفعال و درخواست شماره پس از ورود |
| حفاظت درخواست | الزامی بودن CSRF و escape شدن محتوای کاربر |
| داده نمونه | اجرای تکراری و حفظ رمز و داده موجود |

این آزمون‌ها رفتار مشخص نسخه آموزشی را بررسی می‌کنند.

در مرورگر Chromium نیز صفحه اصلی در عرض ۱۴۴۰ و ۳۹۰ پیکسل، ورود کاربر، ثبت آگهی رایگان با ارقام فارسی، وضعیت انتظار تأیید و پاسخ 404 به مهمان برای آگهی خصوصی بررسی شد. صفحه اصلی، داشبورد و فرم در عرض ۳۹۰ پیکسل اسکرول افقی نداشتند و خطای JavaScript مشاهده نشد. تصاویر واقعی این بررسی در همین پوشه قرار دارند. اسکریپت ویندوز در این محیط Linux اجرا نشده است؛ دستورهای دستی ویندوز نیز در راهنما آمده‌اند.

## آزمایش دستی ده‌دقیقه‌ای

1. مهمان فهرست را ببیند و با دو فیلتر جست‌وجو کند.
2. کاربر تازه ثبت‌نام کند؛ آگهی با عکس و مبلغ فارسی بسازد.
3. آگهی هنوز عمومی نباشد و در صفحه «آگهی‌های من» دیده شود.
4. مدیر آن را تأیید کند و در فهرست عمومی دیده شود.
5. حساب دوم آن را نشان کند و شماره را با کلیک نمایش دهد.
6. حساب دوم با تغییر URL نتواند آگهی را ویرایش کند.
7. مالک آگهی را ویرایش کند؛ وضعیت دوباره انتظار تأیید شود.
8. پس از تأیید مجدد، مالک «فروخته شد» را بزند؛ آگهی عمومی ناپدید شود.
9. صفحه حذف را باز کنید؛ تا زدن دکمه تأیید هیچ داده‌ای حذف نشود.
10. صفحه‌ها را در عرض موبایل بررسی کنید.

## خطاهای رایج

| خطا یا نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `No module named django` | فرمان با Python اشتباه اجرا شده | از Python داخل `.venv` استفاده کنید |
| `no such table` | migration اجرا نشده | `python manage.py migrate` |
| دسته و شهر خالی هستند | داده نمونه یا داده مدیر ساخته نشده | `python manage.py seed_demo` یا ساخت داده در Admin |
| آگهی در صفحه اصلی نیست | هنوز تأیید نشده، رد شده یا فروخته‌شده است | وضعیت را در داشبورد یا Admin بررسی کنید |
| ورود به Admin ممکن نیست | حساب عادی است | `python manage.py createsuperuser` |
| رمز نمونه کار نمی‌کند | حساب قبلاً ساخته و رمز عوض شده | `python manage.py changepassword demo` |
| پورت در استفاده است | سرور دیگری روی 8000 اجرا شده | `python manage.py runserver 127.0.0.1:8001` |
| تصویر دیده نمی‌شود | فایل media موجود نیست یا تنظیم سرو کردن آن درست نیست | مسیر فایل و `MEDIA_ROOT` را بررسی کنید؛ در توسعه DEBUG روشن باشد |
| پاسخ 403 برای فرم | CSRF یا Origin نادرست | فرم را از همان آدرس سرور باز کنید؛ CSRF را خاموش نکنید |
| `DisallowedHost` | میزبان در ALLOWED_HOSTS نیست | میزبان دقیق را در متغیر محیطی اضافه کنید |
| خطای نصب Pillow | Python بسیار قدیمی یا نامتناسب با بسته است | Python 3.12 و pip به‌روز داخل محیط مجازی استفاده کنید |

برای نصب در محیط فاقد اینترنت، بسته‌ها را روی سیستم دارای اینترنت با `pip download -r requirements.txt -d wheels` دریافت و با `pip install --no-index --find-links=wheels -r requirements.txt` نصب کنید. نسخه Python و معماری دو سیستم باید با wheelهای دانلودشده سازگار باشد.
